# Architecture decision records

`0001` through `0010` sit flat in this directory and stay exactly where they are, with the names and numbers they already have. They are cited by number from both sprint plans, from fifteen ticket files, and from comments in the code, and moving them would break every one of those references in exchange for tidiness. Treat them as the foundational set: decisions made before there was more than one engine, most of which still bind the whole repo. Several of them are about Helios only because Helios was the only engine at the time, so read one before assuming it does not apply to you.

A new ADR goes in `iris/`, `atlas/` or `shared/`, and each of those directories numbers from `0001` independently. Two squads writing at once can therefore never collide on a number, which is the entire reason the subdirectories exist. `shared/` is for a decision that binds more than one engine; a decision that affects only one engine goes in that engine's directory even if it was made in a meeting about everything. There is no template and no index. Ten ADRs have been written in a consistent format by reading the previous one, which is process enough.

Cite an ADR by directory and number: `ADR-IRIS-0001`, `ADR-ATLAS-0001`, `ADR-SHARED-0001`. A bare `ADR-0001` therefore means the flat foundational one and can mean nothing else, which is why the engine name is part of the citation rather than a prefix you may drop when it seems obvious. For example, Iris's retry policy is `ADR-IRIS-0001` (`iris/0001-retry-policy-and-the-resume-route-for-iris.md`), while the rule that every model call routes through the AI Gateway is `ADR-0006` (`0006-all-model-calls-route-through-ai-gateway.md`).
